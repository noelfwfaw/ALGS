# AlGS

**单模拟器多游戏任务调度脚本**

---

AlGS 基于 [AzurLaneAutoScript](https://github.com/LmeSzinc/AzurLaneAutoScript) 框架改造：在一个 Android 模拟器中运行多个游戏，按任务排期依次执行。每个任务独立记录下次运行时间，到期后自动启动模拟器完成对应操作，结束后关闭游戏。

当前支持 7 个游戏、79 个任务，另有 2 个不参与排期的独立工具。

限时活动「艾吉斯未解之迷」只做扫荡：进入活动 → 选带 CLEAR 的已通关关卡 → 点「扫荡」→ MAX 拉满次数 → 开始扫荡 → 确认结算。**关卡必须先手动通关**（画面上显示 CLEAR）；脚本不点「作战准备」、不负责开荒，没通关就启用会停在选关页。MAX 会自动把次数拉到体力用尽；当剩余体力连一把都不够时（弹窗把「扣除后剩余」标红），脚本不点「开始扫荡」，直接收工按日更排到次日。**新任务默认为关闭，需要在 WebUI 苍雾分组勾选启用**；联合讨伐提醒弹窗会自动取消。活动结束后把本任务关掉即可。

通行证与卡厄思肉鸽均为**默认关闭**，要在 WebUI 的卡厄思分组里勾选启用。卡厄思肉鸽遇到未知页面或未匹配事件时不会盲点兜底，而是停机等待人工确认。

服务器维护期间客户端会停在全屏维护公告页，进不了游戏。脚本认出这一页后读取「剩餘時間」倒计时，把卡厄思已到期的任务统一推迟到维护结束（另留 2 分钟给客户端重连、校验补丁）；期间不发任何点击、不触发重启，其它游戏的任务照常执行。倒计时读不出来时改为 10 分钟后再来检查一次。手动跑任务时若正在维护，命令行会提示 `declined to boot` 并跳过。

奖励弹窗（「确认领取 / 请点击屏幕继续」那个全屏面板）做成了通用组件：点在标题下方的提示文字上，不点道具卡（点卡会开道具详情）；面板是半透明遮罩，底下的页面照旧在渲染，所以任何任务都要先问弹窗、再问底下的页面。以后新增别的领奖场景，只要把那张弹窗的按钮加进组件的列表就行，不用再写一遍「点掉弹窗」。

<a name="start"></a>

## 🚀 使用

1. 准备好 `toolkit/`（见[安装与更新](#update)）与 MuMu 模拟器，分辨率设为 1280×720，安装并登录游戏。
2. 运行 `start_algs.bat`，脚本会连接模拟器并启动管理界面。
3. 在浏览器中打开管理界面（默认端口 22267）。
4. 在「Alas 设置 → 模拟器设置」中填写模拟器的 adb 地址（IP 与端口），并选择已安装的游戏服务器。该选项只决定启动时先打开哪个游戏，后续按任务自动切换。
5. 在对应分组下勾选任务，填写选项后保存。
6. 点击「开始」立即执行，或等待排期自动运行。
7. 需要立刻执行某个游戏的当轮任务时，点击「一键全跑 <游戏>」。该操作仅将已启用任务的下次运行时间置为当前时间，调度器按优先级依次执行；未启用的任务不会被打开。

界面里的任务名都带游戏前缀（苍雾 / 失落 / 棕尘 / 卡厄思 / 交错 / 星之 / 嘟嘟 / 琐呐），多游戏同时勾选时便于区分。

关闭浏览器不影响后台调度。

<a name="update"></a>

## 🔄 安装与更新

- ❗**新机器请下载 Release 里的完整包** `AlGS-vX.Y.Z-full.zip`（约 270 MB，内含 `toolkit/`：固定的 Python 3.7.6、adb 和全部依赖）。解压后进入 `AlGS` 文件夹，双击 `start_algs.bat` 就能启动 WebUI，不用另装 Python，也不用联网装依赖。GitHub 的 `Source code (zip)` **只有代码**、不含 `toolkit/` 和 `.git/`。
- 只下了 `Source code (zip)` 也能用：第一次双击 `start_algs.bat` 时，脚本会自动从最新 Release 下载 `toolkit.zip`（约 190 MB，只下一次）并解压；`curl.exe` / `tar.exe` 都是 Win10 自带，缺失时回退 PowerShell。GitHub 慢的话先设置 `HTTPS_PROXY` 环境变量再运行；自动下载失败时脚本会打印完整包地址。
- **升级**：下载新版 `Source code (zip)` 覆盖解压到原目录，**保留 `config/` 与 `toolkit/`**（任务配置、NextRun 排期、兑换码账本都在 `config/`；`toolkit/` 是运行环境）。想换干净环境也可以直接下新版完整包，再把旧 `config/` 拷过去。
- 维护者发版：推一个 `v*` tag 就会触发 `.github/workflows/release-assets.yml`，由 GitHub Actions 在云端提取 `toolkit/`、打包并上传上面两个 asset，本机不用传大文件；也可以手动 `workflow_dispatch` 指定 tag 给已发的版本补打包。`toolkit/` 不在 git 里，CI 从上游 ALAS 的完整安装包取同一套 Python 3.7 环境（两边 `requirements.txt` 一致，`mxnet==1.6.0` 没有 Windows wheel，重装不出来）。`toolkit\python.exe -m dev_tools.make_full_package --tag vX.Y.Z` 仍可本地兜底生成两个包。
- **内置更新器是 git 更新器**，靠 `git fetch` / `git log` / `git reset --hard origin/master` 工作，只适用于 `git clone https://github.com/noelfwfaw/ALGS` 出来的目录。压缩包安装没有 `.git/`，WebUI 的「更新」页会提示不可用，也不会去改写目录。
- 默认 `AutoUpdate: false`、`CheckUpdateInterval: 0`、`AutoRestartTime: null`，避免刚解压的目录被自动 `git init` + `reset --hard` 重置。想启用内置更新器：改用 git clone 安装，再到 `config/deploy.yaml` 把三项改成 `true` / `5` / `'03:50'`。
- 更新源固定为 AlGS 仓库；早期配置里指向上游 ALAS / StarRailCopilot 的地址（`global`、`cn`、lyoko / gitee 镜像等）会自动纠正，指向上游 CDN 更新包的通道已关闭，避免更新时把目录换成别的项目的代码。
- 版本号与变更内容见 [Releases](https://github.com/noelfwfaw/ALGS/releases)。

## ⚙️ 配置

### 苍雾世界

- 远征：两支队伍分别配置任务（训练、防卫、攻击、火力、支援）与时长（4、8、12 小时），不使用时选择「不派遣」。已派出的队伍时长不可修改，配置只影响下一次派出。
- 核心制造：周一至周日各配置一个关卡类型，选择「不刷」跳过当天。场数为 `0` 时按现有体力尽量刷，否则按填写数量执行。
- 演习：默认使用代理作战。关闭后逐场播放战斗过程。
- 精英商店：过滤器可选「全部」「自定义」「不买」。购买清单按名称子串匹配，`>` 分隔多个关键词，`!` 开头表示排除，`#` 开头为注释。排除规则在所有档位下生效。清单从上往下、同一行从左往右就是优先级：脚本先把优先级高的一批买光，购买弹窗里点「最大」一次买到货架余量和金币允许的量；金币不够买下一件时停手，第二天 05:00 再来。
- 后勤商店：过滤器与清单格式同精英商店，默认「全部」并排除盾币，同样按清单优先级买满、钱不够第二天再来。
- 荣誉凭证：清单用于校验货架第一格是否为指定商品，名称不匹配则不购买；匹配时点「最大」买满，凭证不够则第二天再来。

### 失落之剑

- 好感对话：填写角色名，简繁需与游戏内一致，未找到或当日已完成的角色跳过。
- 领主突袭：开启「扫荡剩余次数」后完成一场实战并扫荡剩余免费次数；关闭后仅执行一场。
- 宝藏探索：可分别开启领取宝藏与每日免费探查。免费次数用尽后需要消耗钻石，脚本会跳过。
- 公会：有红点时消耗金币完成捐献与投资，金币不足时不执行。
- 阿瓦隆：默认关闭，在「进攻城市」中选择目标城堡（埃塞尔城 / 爱尔亚城 / 埃尔达利亚城 / 卡美洛城 / 廷塔哲城 / 默西亚城）；自动领取排行结算弹窗并完成挑战，遇到已占领或休赛期的城主弹窗时读取「下次时间」倒计时精准排至下次开放（倒计时不可读时回退延后至下周）。

### 交错战线

- 邮箱与任务：都是「一键领取」。脚本按按钮是否金色高亮判断还有没有可领，变暗（或换成别的图标）就停手，不需要填任何配置。任务先领日常、再切周常，周常没得领时立即退出；「剧情任务」不处理。
- 兑换码：从 GameKee 抓交错战线的兑换码，新码在「菜单 → 设置 → 补给兑换」逐个提交，已处理的不再重试；在任务的「兑换码」设置里勾「清除兑换码记录」，下一次运行会清空记录、把所有码重兑一遍（勾一次只生效一次，之后自动取消）。
- 通行证（勘探指南）：从大厅左侧图标进入，点右上「任务」后在每日、每周、本期页逐行点「领取奖励」（每领一个下一个顶上来，领完的行会消失），再点框外关闭弹窗，最后点「全部领取」领等级奖励；「全部领取」消失即没有可领的。「升级」与剧情任务不处理。
- 驻员换班：填写一队、二队各自的驻员时长（默认 15.5h / 8.5h）。每次运行「交错基地」都会换一次班，下次运行时间按这次换上的队伍时长计算；想让某队多值一会儿，直接改任务的下次运行时间即可。
- 队伍对齐：脚本不做混编队伍，以第一个能读到的预设为准，把所有设施统一对齐到它的另一队。
- 订单库：先扫自己的库，再用「选择好友」逐个翻好友的库；买不起的构建订单按缺料去合成。1 个稀有黑匣需要 280 原型石英、40 压电石英、40 熔融石英，压电与熔融各由 8 原型石英合成。
- 每日探索：配置里选一个子项（资源采集 / 芯片嵌合 / 跃升行动共 15 项），脚本直接根据锁定态定位最高可扫荡层（未开放时跳过；若仅前几层已通关则自动回退到可扫荡层）。芯片嵌合与跃升行动按标题模板定位（兼容「明日开放」沉底重排后的位置变化）。扫荡会消耗全部体力；掉落加成提示自动点「使用」；扫荡完成点右下角「奖励」标题关掉结算框。
- 芯片分解：进仓库「芯片」页批量分解，按配置的星级上限从 1 星依次勾选至目标星级并确认出售，无满足条件芯片时直接退出。
- 模拟军演：从「出击 → 模拟军演 → 镜像竞技」进入，不管对手战力，固定打列表第一个，模拟次数用尽弹出「模拟次数购买」时直接关闭并停手（绝不花费付费道具购买）；战斗不能跳过，胜负都停在同一个结算页，脚本点屏幕下方空白处继续。打完后进「商店兑换」，从左上第一件开始一直买（能选数量的按「最大」买满），买过的商品会变暗排到队尾，第一件变成星币或技术点就停，不买这两样。
- 周本（碎星虚影）：从「出击 → 活动探索 → 碎星虚影」进入（微晶打满后卡片移到列表队尾时自动左滑查找），读左下角「本周报酬微晶」与重置倒计时，打满上限后按倒计时排至下周重置。选图与 1~6 关（5、6 关自动滚动到底部），自动确认溢出/满上限弹窗并踩 `PUSH` 机关、追击敌人与 BOSS。**暂时对「诺斯虚影」和「尼克罗虚影」未完美适配，建议打「戈里刻虚影」**；另提供「忽略微晶上限（调试）」开关用于通关测试。
- 跳过剧情（独立工具）：在交错战线菜单中以工具页形式提供，手动启动后自动识别并点击右上角「跳过」及确认弹窗，不参与定时排期与「一键全跑」。
- ❗**战斗动画必须关掉**：进游戏「设置 → 战斗」，把「战斗动画」设为关闭。军演的战斗不能跳过、只能等它自己打完，动画开着时一场要播好几分钟，而脚本等结算页最多 5 分钟，超时会被判成「战斗没打完」并中止本轮军演。基地、探索、每日任务都不受影响，只有军演会踩这个坑。
- ❗**图像质量设为「高」**：进游戏「设置」，把图像质量调到高。脚本的按钮、图标与结算页素材都是在高画质下截的，调到中或低之后渲染细节会变，模板匹配容易认不出，表现是「明明在页面上却点不动」，任务卡住或误判。

- 邮件领取、每日活跃与通行证不需要额外配置：邮箱有未领附件时一键领取，活跃领完后再逐本领取「环游手册」的每日、每周与等级奖励。

### 星之救援者（工具）

- 昵称：留空时每轮随机生成，仅支持字母与数字，长度 4~16 位；中文或带含义的单词可能被游戏判「包含无法使用的字」，建议保持留空。

- 刷初始次数：跑满这么多轮就停，**不重置**，号留在游戏里。`0` 为不限（默认）。
  和目标角色一起用时先到哪个算哪个；在重置之前判定，不会白丢最后一轮的号。
- SSR 数量兜底：目标角色没凑够，但本轮读到的 SSR **只数**（重复抽到的也算）达到设定值也停下，**不重置**，号留在游戏里——数量够多也算不错的初始号。`0` 为不启用（默认）；和目标角色同时设置时目标优先，两个都达成按「目标达成」处理。
- 当前轮数：跑刷初始时工具页顶部会显示「第 N 轮」，从点「启动」起算、每次启动归零，不用翻日志。
- 停止节点：节点 1 到昵称输入前、节点 2 引导走完、节点 3 验号结束；用于调试或分段验证，停下时都不重置账号。
- 闪退重启：游戏进程消失、退回桌面，或客户端意外回到标题/登录页时自动重登，本轮轮数不递增。重进若已在大厅、旅程、战斗或剧情页，按落点接着跑（大厅接领奖 / 抽卡 / 验号，旅程从当前画面续跑，无 SKIP 的剧情页先点完剧情），不再空转引导链；仍在引导期则按当前画面重扫按钮表，从能认到的节点继续。登录会先给客户端和服务器留足落定时间，选完账号落到标题页才补点 `Touch to Start`；登录走不完、引导结束却没到旅程时明确停下并推送，不会在错误画面上一直空转。连续 3 次重启仍不行才停止。
  重进游戏会落在游戏自己记录的开荒进度上，已过的前置引导不会重放，各段按当前画面重新接。

## ⚠️ 注意事项

### 环境

- 分辨率固定 1280×720，仅支持模拟器。
- 启动前需要模拟器处于运行状态，`start_algs.bat` 会自动完成 adb 连接。
- 体力或次数不足时任务会跳过，不会等待结算。

### 资源消耗

- 活动开荒、推主线、迷宫、竞技场均会实际消耗体力、次数或票券。
- 刷初始会清空账号上可抽取的资源，并可能重置服务器账号进度，仅适用于空号或小号。该功能仍在测试阶段，兼容性有限；重置细节见[星之救援者的注意事项](#starsavior-notes)。

### 星之救援者

- **账号前提**：模拟器里要先登录 Google 账号，并且该账号已在游戏里建过号、能出现在「选择账号」列表里。脚本只点「Sign in with Google」和列表第一行的已有账号，不处理注册、密码、验证码、二次验证或新增 Google 账号；列表里有多个账号时建议只保留要刷的那个。
- **重置不可逆**：目标未达成时，脚本会进「设置 → 账号管理 → 重置服务器账号」并输入确认语，重置**当前登录账号的服务器进度**。角色、进度与已经消耗的抽卡资源都不会回来，只适用于空号或小号，**不要在主号上运行**。达标、停在节点、刷满轮数或只验号时都不会重置，号留在游戏里。
- **运行中不要手动操作**：登录、引导、旅程、结算都按画面状态推进，手动点按、切到别的应用或锁屏会让脚本点错位置。需要停止时点工具页的「停止」。
- **验号**：只统计 SSR，按角色名与团名匹配，同一角色重复抽到按数量累计（1~4 只）。识别基于截图 OCR，偶发误读时以游戏内实际结果为准，关键账号建议人工复核。
- **耗时**：一轮要完整走完登录、引导、旅程、结算、领奖、抽卡与验号，耗时较长；闪退会自动重启并接着本轮继续。
- **推送**：每轮验号后都会用 `Alas → Error → OnePushConfig` 的 Onepush 配置推一条结果（SSR 列表 + 目标进度），没达标也推；刷很多轮时会收到很多条，不想收就把 `provider` 留空。
- **环境**：模拟器需要带 Google 服务框架。截图与控制方案按「Alas 设置 → 模拟器设置」选择：MuMu 12（>=3.8.13）可用 `nemu_ipc`，雷电 9/14 可用 `ldopengl`，控制方案推荐 `MaaTouch`。星之救援者转场和动画多，截图慢会让识别滞后、点按错过时机。
- **独占模拟器**：刷初始是独立工具，启动时会冷启动星之救援者并独占模拟器；先等其它游戏的排期任务结束或手动停掉，不要和排期任务同时运行。

### 异常处理

- 游戏卡死、掉线或停留在弹窗时，脚本会保存最近 60 张截图与日志，随后重启游戏继续执行。
- 文本日志与错误诊断包会自动按体积轮转并结合保留天数与容量上限清理，避免长期运行持续占用磁盘空间。
- 无法识别维护公告页，维护期间会按各游戏的启动上限等待；同一任务连续失败 3 次后调度器停止，需要手动重新开始。
- 错误推送：出问题时会按 `Alas → Error → OnePushConfig` 里的 Onepush 配置推一条消息，不用盯着 WebUI。包括脚本错误、需要人工接管、认不出页面、配置或设备初始化失败、同一任务连续失败 3 次、工具跑失败（例如刷初始重置账号没成功）；游戏卡死、误点过多、客户端异常、游戏不在运行这类会自动重启恢复的错误也会推一条。运行以失败结束时，WebUI 侧栏显示为出错状态，而不是「已完成」。没填 `provider` 时（默认 `provider: null`）不推送；配置方法见 [Onepush 配置](https://github.com/LmeSzinc/AzurLaneAutoScript/wiki/Onepush-configuration-%5BCN%5D)。
- 客户端更新与资源下载提示只记录并停止，不会代为操作；苍雾世界的资源包是例外，脚本会确认并等待下载完成。
- 失落之剑闲置约 3 分钟后会隐藏界面，脚本会自动恢复后再继续。
