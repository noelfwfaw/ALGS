# AlGS

**单模拟器多游戏任务调度脚本**

![games](https://img.shields.io/badge/games-5-success?style=flat-square)

---

AlGS 基于 [AzurLaneAutoScript](https://github.com/LmeSzinc/AzurLaneAutoScript) 框架改造：在一个 Android 模拟器中运行多个游戏，按任务排期依次执行。每个任务独立记录下次运行时间，到期后自动启动模拟器完成对应操作，结束后关闭游戏。

当前支持 5 个游戏、42 个任务，另有 1 个不参与排期的独立工具。

## 🚀 使用

1. 准备好 `toolkit/`（见[安装与更新](#update)）与 MuMu 模拟器，分辨率设为 1280×720，安装并登录游戏。
2. 运行 `start_algs.bat`，脚本会连接模拟器并启动管理界面。
3. 在浏览器中打开管理界面（默认端口 22267）。
4. 在「Alas 设置 → 模拟器设置」中填写模拟器的 adb 地址（IP 与端口），并选择已安装的游戏服务器。该选项只决定启动时先打开哪个游戏，后续按任务自动切换。
5. 在对应分组下勾选任务，填写选项后保存。
6. 点击「开始」立即执行，或等待排期自动运行。
7. 需要立刻执行某个游戏的当轮任务时，点击「一键全跑 <游戏>」。该操作仅将已启用任务的下次运行时间置为当前时间，调度器按优先级依次执行；未启用的任务不会被打开。

界面里的任务名都带游戏前缀（苍雾 / 失落 / 棕尘 / 卡厄思 / 交错 / 星之），多游戏同时勾选时便于区分。

关闭浏览器不影响后台调度。

## 🔄 安装与更新

- GitHub Release 的 Source code 压缩包**只包含代码**：不含 `toolkit/`（固定的 Python 3.7.6、git、adb）和 `.git/`。`start_algs.bat` 需要 `toolkit\python.exe`，首次安装请从上游 [AzurLaneAutoScript](https://github.com/LmeSzinc/AzurLaneAutoScript) 的完整安装包复制整个 `toolkit/` 到本目录。
- **内置更新器是 git 更新器**，靠 `git fetch` / `git log` / `git reset --hard origin/master` 工作，只适用于 `git clone https://github.com/noelfwfaw/ALGS` 出来的目录。压缩包安装没有 `.git/`，WebUI 的「更新」页会提示不可用，也不会去改写目录；升级时下载最新 Release 覆盖代码即可，**保留 `config/` 与 `toolkit/`**（任务配置、NextRun 排期、兑换码账本都在 `config/`）。
- 默认 `AutoUpdate: false`、`CheckUpdateInterval: 0`、`AutoRestartTime: null`，避免刚解压的目录被自动 `git init` + `reset --hard` 重置。想启用内置更新器：改用 git clone 安装，再到 `config/deploy.yaml` 把三项改成 `true` / `5` / `'03:50'`。
- 更新源固定为 AlGS 仓库；早期配置里指向上游 ALAS / StarRailCopilot 的地址（`global`、`cn`、lyoko / gitee 镜像等）会自动纠正，指向上游 CDN 更新包的通道已关闭，避免更新时把目录换成别的项目的代码。
- 版本号与变更内容见 [Releases](https://github.com/noelfwfaw/ALGS/releases)。

## ⚙️ 配置

### 苍雾世界

- 远征：两支队伍分别配置任务（训练、防卫、攻击、火力、支援）与时长（4、8、12 小时），不使用时选择「不派遣」。已派出的队伍时长不可修改，配置只影响下一次派出。
- 核心制造：周一至周日各配置一个关卡类型，选择「不刷」跳过当天。场数为 `0` 时按现有体力尽量刷，否则按填写数量执行。
- 演习：默认使用代理作战。关闭后逐场播放战斗过程。
- 精英商店：过滤器可选「全部」「自定义」「不买」。购买清单按名称子串匹配，`>` 分隔多个关键词，`!` 开头表示排除，`#` 开头为注释。排除规则在所有档位下生效。清单从上往下、同一行从左往右就是优先级：脚本先把优先级高的一批买光，购买弹窗里点「最大」一次买到货架余量和金币允许的量；金币不够买下一件时停手，第二天 05:00 再来。
- 后勤商店：过滤器与清单格式同精英商店，默认「全部」并排除盾币，同样按清单优先级买满、钱不够第二天再来。
- 荣誉凭证：清单用于校验货架第一格是否为指定商品，名称不匹配则不购买；匹配时点「最大」买满，凭证不够则第二天再来。

### 失落之剑

- 好感对话：填写角色名，简繁需与游戏内一致，未找到或当日已完成的角色跳过。
- 领主突袭：开启「扫荡剩余次数」后完成一场实战并扫荡剩余免费次数；关闭后仅执行一场。
- 宝藏探索：可分别开启领取宝藏与每日免费探查。免费次数用尽后需要消耗钻石，脚本会跳过。
- 公会：有红点时消耗金币完成捐献与投资，金币不足时不执行。
- 迷宫：节点优先级固定，未成功进入或确认 BOSS 时推迟 3 小时重试，仅在地图显示完成后排至下周。
- 兑换码：兑换记录保存在本地，删除对应条目可重新尝试。

### 棕色尘埃2

- 快速狩猎：八项次数分为两组预算，狩猎场、金币、史莱姆合计不超过 15 次，圣石洞穴五种属性合计不超过 10 次，超出时拒绝执行。
- 活动：可分别设置战斗模式与每个模式的场次，活动商店按兑换优先级消费活动币。
- 兑换码：兑换记录保存在本地，删除对应条目可重新尝试。

### 卡厄思梦境

- 兑换码：兑换记录保存在本地，删除对应条目可重新尝试。兑换码站点把国服与全球服的码混在一起发，本机的全球客户端兑不了国服码（输入法也送不进中文），这类码会在本地记为失败，不再每天重试。

### 交错战线

- 邮箱与任务：都是「一键领取」。脚本按按钮是否金色高亮判断还有没有可领，变暗（或换成别的图标）就停手，不需要填任何配置。任务先领日常、再切周常，周常没得领时立即退出；「剧情任务」不处理。
- 通行证（勘探指南）：从大厅左侧图标进入，点右上「任务」后在每日、每周、本期页逐行点「领取奖励」（每领一个下一个顶上来，领完的行会消失），再点框外关闭弹窗，最后点「全部领取」领等级奖励；「全部领取」消失即没有可领的。「升级」与剧情任务不处理。
- 驻员换班：填写一队、二队各自的驻员时长（默认 15.5h / 8.5h）。每次运行「交错基地」都会换一次班，下次运行时间按这次换上的队伍时长计算；想让某队多值一会儿，直接改任务的下次运行时间即可。
- 队伍对齐：脚本不做混编队伍，以第一个能读到的预设为准，把所有设施统一对齐到它的另一队。
- 订单库：先扫自己的库，再用「选择好友」逐个翻好友的库；买不起的构建订单按缺料去合成。1 个稀有黑匣需要 280 原型石英、40 压电石英、40 熔融石英，压电与熔融各由 8 原型石英合成。
- 每日探索：配置里选一个子项（资源采集 / 芯片嵌合 / 跃升行动共 15 项），脚本自动点它最高的已解锁层。芯片嵌合选项多，列表会自动滚动到底再按行点。扫荡会消耗全部体力；掉落加成提示自动点「使用」；扫荡完成没有退出按钮，脚本点右下角的「奖励」标题关掉结算框。
- 模拟军演：从「出击 → 模拟军演 → 镜像竞技」进入，不管对手战力，固定打列表第一个，每天把 10 次模拟次数打满；战斗不能跳过，胜负都停在同一个结算页，脚本点屏幕下方空白处继续。打完后进「商店兑换」，从左上第一件开始一直买（能选数量的按「最大」买满），买过的商品会变暗排到队尾，第一件变成星币或技术点就停，不买这两样。

### 星之救援者（工具）

- 昵称：留空时每轮随机生成，仅支持字母与数字，长度 4~16 位。
- 达标条件：「任意一个角色」在任一目标达标时停止；「全都要」需所有目标均达标。
- 目标角色：最多 7 个，格式为 `名字@团`，同名角色需通过团名区分。
- 刷初始次数：跑满这么多轮就停，**不重置**，号留在游戏里。`0` 为不限（默认）。
  和目标角色一起用时先到哪个算哪个；在重置之前判定，不会白丢最后一轮的号。
- 当前轮数：跑刷初始时工具页顶部会显示「第 N 轮」，从点「启动」起算、每次启动归零，不用翻日志。
- 停止节点：可分阶段运行，用于调试或分段验证。
- 闪退重启：游戏进程消失或退回桌面时自动重启，并从「等游戏画面」重走本轮状态机；连续 3 次重启仍不行才停止并推送。
  重进游戏会落在游戏自己记录的开荒进度上，已过的前置引导不会重放，各段按当前画面重新接。

<a name="notes"></a>

## ⚠️ 注意事项

### 环境

- 分辨率固定 1280×720，仅支持模拟器。
- 启动前需要模拟器处于运行状态，`start_algs.bat` 会自动完成 adb 连接。
- 体力或次数不足时任务会跳过，不会等待结算。

### 资源消耗

- 活动开荒、推主线、迷宫、竞技场均会实际消耗体力、次数或票券。
- 刷初始会清空账号上可抽取的资源，并可能重置服务器账号进度，仅适用于空号或小号。该功能仍在测试阶段，兼容性有限。

### 异常处理

- 游戏卡死、掉线或停留在弹窗时，脚本会保存最近 60 张截图与日志，随后重启游戏继续执行。
- 无法识别维护公告页，维护期间会按各游戏的启动上限等待；同一任务连续失败 3 次后调度器停止，需要手动重新开始。
- 错误推送：出问题时会按 `Alas → Error → OnePushConfig` 里的 Onepush 配置推一条消息，不用盯着 WebUI。包括脚本错误、需要人工接管、认不出页面、配置或设备初始化失败、同一任务连续失败 3 次、工具跑失败（例如刷初始重置账号没成功）；游戏卡死、误点过多、客户端异常、游戏不在运行这类会自动重启恢复的错误也会推一条。运行以失败结束时，WebUI 侧栏显示为出错状态，而不是「已完成」。没填 `provider` 时（默认 `provider: null`）不推送；配置方法见 [Onepush 配置](https://github.com/LmeSzinc/AzurLaneAutoScript/wiki/Onepush-configuration-%5BCN%5D)。
- 客户端更新与资源下载提示只记录并停止，不会代为操作；苍雾世界的资源包是例外，脚本会确认并等待下载完成。
- 失落之剑闲置约 3 分钟后会隐藏界面，脚本会自动恢复后再继续。
