# AlGS

**一个模拟器，多个游戏，勾几个任务就自动跑完的挂机脚本。**

AlGS 不要求游戏 24 小时挂着。它记住每个任务下次该什么时候跑，到点了自己启动模拟器、把该做的做完、再关掉——白天照常用电脑，凌晨那趟收菜它自己会去。

目前适配 **3 个游戏、33 个任务**（日常为主，失落之剑有两个周常），都在同一个模拟器里按顺序执行。

## 能做什么

### 苍雾世界（Hazeworld）

| 任务 | 它替你做的事 |
|---|---|
| **邮件** | 打开邮箱，一键领取全部附件 |
| **指挥室** | 一键收取所有产出；两支远征队按你配的任务和时长派出，到期自己回来领取、再派一次 |
| **演习** | 花掉当天的演习券打完竞技场，默认走代理作战一路扫（想看战斗过程可以关掉代理） |
| **好友** | 一键点赞全好友 |
| **任务** | 每日 / 每周 / 每月三栏的任务奖励一键领取，连积分条攒满的宝箱也一起开 |
| **通行证** | 先领通行证任务（任务给的积分才能升级），再一键领取等级奖励 |
| **支援角色** | 把每个支援角色的友情币（绿币）领掉，每日上限 50000 |
| **核心制造** | 扫荡今天开放的关卡，能刷多少刷多少，体力花完为止；扫完会再读一次体力，确认真的花出去了，没花够就再扫一遍 |

| **推主线** | 冒险里按普通 → 困难 → 地狱依次往下推，每个难度推到打不过为止（输了退回主界面，换下一个难度接着推）；章节最后一关的剧情会自己点 Skip |
| **领主突袭** | 每天先真打一场（伤害榜要这一场），再把剩下的免费次数扫荡掉；三次用完就停，不碰付费票 |
| **小队副本** | 每天一次，自动进房间匹配、等招募和战斗结束，结算页「CLEAR」后返回 |
| **星辰轮回** | 三个冒险区域各挑战一次，每个区域打一到两波，打完退出 |
| **副本扫荡** | 进任意一个可扫荡的副本，一键选择把金币 / 经验书 / 属性石三个日常免费次数一起扫掉 |

| **圆桌升级** | 点「升级」提升骑士团等级，一直升到金币和经验书不够为止 |
| **好感对话** | 按配置的角色名逐个找到角色，把当天的好感对话次数用掉（对话里的选项自动选第一条） |
| **商店** | 每日 / 每周 / 每月三个页签的免费礼包各领一次，只碰免费的那张卡，付费的一个不动 |
| **宝藏探索** | 领取挂机累积的宝藏，并用掉每天一次的免费快速探查（弹出来要 90 钻时自动放弃） |

| **任务奖励** | 每日 / 每周 / 史诗三个页签全部领取，顺手把赛季通行证里所有能领的等级奖励也领掉 |
| **兑换码** | 每天去 GameKee 的兑换码页抓一次，把没兑过的码一个个填进游戏的「兑换优惠券」；本机留着记录，兑过的、用过的、过期的都不会再试 |

### 棕色尘埃2（Brown Dust II）

| 任务 | 它替你做的事 |
|---|---|
| **免费抽抽乐** | 服装和装备两个分类各抽一次每日免费；看不到「免费」两个字就一次都不点，不会花掉一张券 |
| **快速狩猎** | 回狩猎场把狩猎场 / 金币 / 史莱姆的每日次数打掉，再去圣石洞穴把五种属性的火把次数打掉；次数不够时自动收手 |
| **邮箱领取** | 领普通邮箱里的全部附件（商品邮箱和记录页不动） |
| **经营管理** | 打开「经营管理」面板点「一键获得」，把累计奖励一次领完，连结算页一起关掉 |
| **日常任务** | 每日 / 每周两个页签各点一次「全部获得」，区间奖励的宝箱一起收 |
| **活动** | 一期的五件事一个任务跑完，进一次活动页连着做完：剧情跳到没得看为止 → 把每天 5 次活动 AP 花在普通/挑战战斗上（能开荒就一路开荒）→ 魔兽从最低难度往上推、打不穿就停 → 领「任务」木牌里已经做完的助力奖励 → 按你的兑换优先级花活动币。哪一步走不通只跳过那一步，不影响其它几步 |
| **通行证领取** | 靠左列的红点认出哪几张通行证要打开，每张都把「等级奖励」和「每日任务」两页的「全部获得」各按一次——只按奖励页会漏掉任务页里的东西；通行证每期换版式也不用改配置 |
| **兑换码** | 每天去 GameKee 的兑换码页抓一次，在游戏里打开「添加优惠券」网页，把没兑过的码一个个填进去；本机留着记录，兑过的、用过的、无效的都不会再试 |

每个任务都能单独开关。只想收个菜就把其它勾掉，那天就只为这一件事启动模拟器。

## 它什么时候自己跑

这是 AlGS 和普通挂机脚本最不一样的地方：**每个任务自己排下一次的时间，不在该跑的时候它不碰模拟器。**

| 游戏 | 任务 | 什么时候跑 | 为什么是这个时候 |
|---|---|---|---|
| 苍雾世界 | 邮件 / 好友 / 支援角色 | 每天 05:00 | 日刷新，跑一次就够 |
| 苍雾世界 | 核心制造 | 05:00 / 17:00 | 一管体力约半天回满，一天跑两次正好把两管都花掉 |
| 苍雾世界 | 任务 / 通行证 | 05:00 / 12:00 / 18:00 / 23:00 | 任务是在你玩的时候陆续完成的，只在早上领一次等于把一天的任务堆到第二天 |
| 苍雾世界 | 演习 | 05:00 / 17:00 | 演习券每小时回 1 张、上限 15 张，一天只跑一次会白白浪费 9 张 |
| 苍雾世界 | 指挥室（远征） | 最早回来的那支队伍 + 5 分钟 | 队伍什么时候回来是面板上写着的时间，不是配置里的 8 小时 |
| 失落之剑 | 邮箱 / 推主线 / 领主突袭 / 小队副本 / 副本扫荡 / 活动 / 竞技场 / 圆桌升级 / 好感对话 / 商店 / 宝藏探索 / 免费召唤 | 每天 00:00 | 这个游戏的日刷新是零点；这些都是每天一次的次数，攒着一次做完 |
| 失落之剑 | 星辰轮回 | 每周一 00:00 | 周常内容，和迷宫同一个刷新点；每周打一轮，不用每天去 |
| 失落之剑 | 迷宫 | 每周一 00:00 | 一周只能走一次，走完地图上写「完成」，再点也没用 |
| 失落之剑 | 任务奖励 + 赛季通行证 | 每次游戏会话结束时领一遍（跑完勾的任务、关游戏之前），另有 00:00 兜底 | 奖励跟人走，但排在所有任务后面，不会挡住你真正想跑的东西 |
| 失落之剑 | 兑换码 | 每天 10:00 | 抓取只是几个网络请求，**没有新码时连游戏都不碰**；单独一个时间点是为了不和 00:00 那批抢同一次冷启动 |
| 棕色尘埃2 | 免费抽抽乐 / 快速狩猎 / 邮箱领取 / 经营管理 / 日常任务 / 活动 / 通行证领取 | 每天 08:00 | 这个游戏的日刷新是 08:00，这些全是每天一次的次数，攒着一次做完 |
| 棕色尘埃2 | 兑换码 | 每天 10:30 | 同样只是几个网络请求，**没有新码时连游戏都不碰**；和失落之剑的 10:00 错开半小时，两个游戏各自的冷启动不会挤在同一个时刻 |

**每个游戏的日刷新时间不一样，各按各的算**：苍雾世界 05:00，失落之剑 00:00，棕色尘埃2 08:00。这个时间是每个游戏自己的属性，脚本不会拿一个游戏的时间去排另一个游戏的任务。

排在同一时刻的任务会连着跑完，共用一次启动——苍雾世界 05:00 那批是「邮件 → 指挥室 → 支援 → 演习 → 好友 → 核心制造 → 通行证 → 任务」，失落之剑 00:00 那批是一次冷启动把当天的次数全花掉，棕色尘埃2 08:00 那批是「免费抽抽乐 → 快速狩猎 → 经营管理 → 邮箱 → 日常任务 → 活动 → 通行证」，都不会为了下一个任务再开一次模拟器。苍雾世界和失落之剑的队列跑空之后、关游戏之前，脚本还会顺手把任务奖励和通行证领一遍，所以「今天只勾了收菜」也不会漏掉它们。

## 怎么用

1. **把模拟器准备好**：MuMu，分辨率 **1280×720**，adb 端口 **127.0.0.1:16640**，装好游戏并登录。
2. **双击 `start_algs.bat`**。它会先连上模拟器，再起管理界面。
3. **浏览器打开 http://127.0.0.1:22267** 。
4. 在「Alas → Alas设置 → 模拟器设置」里确认「模拟器 Serial」是 `127.0.0.1:16640`，「游戏服务器」选一个**已经装好**的游戏（这只是决定启动时先打开哪个，之后按任务自动切）；然后在对应分组下勾上要跑的任务（名字就是上面那几张表），逐个填好选项，保存。
5. 想立刻跑就点「开始」，或者什么都不做——到点它自己会跑。
6. 只想马上把某个游戏这一轮跑完，点总览页「调度器」下面那个 **一键全跑 苍雾世界 / 一键全跑 失落之剑 / 一键全跑 棕色尘埃2**：它把这个游戏**已勾选**的任务全部改成「现在到期」，调度器照原来的优先级连着跑完，中途只切一次游戏。在任务自己的设置里关掉的不会被它打开，点完的提示里会写明跳过了几个——想连那几个一起跑，先去把它们的开关勾上。

关掉浏览器不影响它，脚本在后台继续按排期工作。

> **「游戏服务器」下拉里的棕色尘埃2 现在能用了**：8 个任务（免费抽抽乐、快速狩猎、邮箱领取、经营管理、日常任务、活动、通行证领取、兑换码）都已跑通，日刷新 08:00。活动那一个任务里跑的是五件事：剧情、战斗、魔兽追踪者、领奖、商店。

> **几个游戏可以同时勾。** 每个任务开跑前，脚本会把属于它的那个游戏切到前台；**切之前一定先把上一个退出**——不看它当时在不在前台，退到后台的照样占着内存，两个游戏同时活着时系统迟早会杀掉其中一个，看起来就像随机闪退。这事跟「任务队列清空后」那个选项无关：那个选项只决定**等着下一个任务的时候**游戏是留着还是关掉（`stay_there` 留在页面里、`goto_main` 回主页、`close_game` 直接关掉），而一旦确定要换游戏，旧的就一定走。代价是每次换游戏都要冷启动一次（失落之剑一分半到两分钟、棕色尘埃2 一分多钟，这段时间它只是在等游戏加载）。

## 配置要点

**远征（苍雾世界 · 指挥室）**：两支队伍各配一个任务（训练 / 防卫 / 攻击 / 火力 / 支援）和一个时长（4 / 8 / 12 小时），不用的队伍把任务选「不派遣」。已经派出去的队伍时长在游戏里是锁死的，脚本只负责到期领取再照配置重新派，所以改配置只影响下一次派出。

**核心制造（苍雾世界）**：周一到周日各配一个类型（生命 / 攻击 / 护甲 / 暴击 / 爆发），选「不刷」就跳过那天。场数只有一个「刷几场」：填 `0` 表示有多少体力刷多少，填具体数字就只刷那么多场。关卡不用配，游戏会沿用你上次打的那一关，出新关卡也不用改脚本。

**演习（苍雾世界）**：默认用代理作战（游戏自己打完，速度快、不挑队伍）。关掉「代理作战」就变成一场一场看战斗过程，慢很多，一般不需要。

**领主突袭（失落之剑）**：只有一个「扫荡剩余次数」开关。开着就是打一场 + 把剩下的免费次数扫掉；关掉就只打那一场，剩下的次数留给你自己扫。

**好感对话（失落之剑）**：填 6 个角色名，照游戏里「角色」页卡片下方写的那个填（简繁要和游戏一致）。脚本在角色网格上按名字找，找不到的、今天已经聊过的会跳过；一个都不填这个任务就空转，不会乱点。

**任务奖励（失落之剑）**：默认在每次会话结束（跑完你勾的任务、关游戏之前）领一遍，所以平时不用管排期；关掉开关就只剩每天 00:00 那一次兜底。

**推主线（失落之剑）**：没有选项，勾上就是每天推一次。三个难度各自推到你打不过为止，所以推不动的日子它也只打一场就换难度，不会反复送。

**宝藏探索（失落之剑）**：两个开关——「领取宝藏」收挂机收益，「每日一次免费快速探查」用掉当天那次免费机会。免费次数用完再点就要 90 钻，脚本看出价格变成钻石就只关弹窗、不付钱。

**公会（失落之剑）**：没有开关，只有一件事要留意——它**要花金币**。有红点的那天，捐献要 100000 金币，公会投资的第一档再要 50000，合计 15 万；金币不够时游戏按钮是灰的、红点也不在，脚本就什么都不按。三项都跟着公会入口那颗红点走：入口没红点，整个任务两帧就结束，连菜单都不会点进去。

**迷宫（失落之剑）**：一周一次，没有选项。节点优先级是照攻略写死的（女神的祝福 > BOSS > 宝箱 > 复活 > 死神的试炼 > 特殊事件），要改只能改代码；想让游戏自己排就关掉这个任务，手动进一次。

**星辰轮回（失落之剑）**：也是一周一次（每周一 00:00），没有选项。三个冒险区域各打一次，打完排到下周。

**兑换码（失落之剑）**：没有选项，每天 10:00 去 GameKee 抓一次。本机的账本在 `config/state/lostsword_codes.json`：兑成功、提示「已使用过」、已过期、以及「点了没读出来」的码都算结算过，不会再试。想让某个码再试一次，把账本里那一条删掉即可。抓取失败（站点挂了、改版式）只会记一行警告并排到明天，不影响别的任务。

**免费抽抽乐（棕色尘埃2）**：只有一个开关。服装、装备两个分类的每日免费各抽一次，靠游戏自己画的红「!」找有免费的卡池——看不到「免费」两个字就一次都不点，不会花掉一张券。

**快速狩猎（棕色尘埃2）**：八个数字，是两组各算各的预算。狩猎场 / 金币 / 史莱姆共用一条体力，三者合计不能超过 15 次；圣石洞穴五种属性共用火把，合计不能超过 10 次。填超了脚本会当场拒绝而不是偷偷截成 15——"我要了 8+8 结果只跑 15"这种惊喜不值得留。填 0 表示不打。当天资源还不够的会自动收手，不会在那里空转等一遍刷不出来战斗。

**兑换码（棕色尘埃2）**：没有选项，每天 10:30 去 GameKee 抓一次。游戏里的路是「大厅右上角方格 → 其他 → 添加优惠券」，弹出来的是一个网页，昵称它已经填好了，脚本只往里填兑换码并按「兑换」。本机的账本在 `config/state/browndust_codes.json`：兑成功、提示「已使用过」、已过期、提示「无效的序列号」、以及「点了没读出来」的码都算结算过，不会再试。想让某个码再试一次，把账本里那一条删掉即可。抓取失败（站点挂了、改版式）只会记一行警告并排到明天，不影响别的任务。

**活动（棕色尘埃2）**：一个任务跑完这一期的五件事，顺序是 **剧情 → 活动战斗 → 魔兽追踪者 → 活动任务 → 活动商店**。只进一次活动页，五件事连着做完才回大厅——以前这是五个独立任务，每块木牌都要重新"回大厅 → 点横幅 → 进活动页"。

顺序不是随手排的：剧情不花任何资源，跳完一集下一集立刻解锁，所以排第一，后面最难的那一步挂了这趟至少把剧情拿到了；战斗花活动 AP、产出活动币；魔兽用独立次数，一场三四分钟，是整趟里最慢也最可能失败的一步；领奖得等上面几步把助力任务做出来；商店花币，只能放最后。

**单步失败不中断整趟**：战斗那一步认不出页面，魔兽、领奖、商店照做。只有"游戏卡死 / 模拟器没了 / 需要人工"才把整趟停下来。日志里每一步都有一个 `Event · xxx` 的分节标题，跳过了哪一步一眼能看见。

**第 1 步 · 剧情**：点底部「剧情」，从列表里找还带着「查看」的那一集，进去点右上角跳过、确认，奖励层点一下回列表，然后下一集。**这一期看完了就什么都不点**，读一眼「行程」里的「还剩N天」记进日志就算做完。活动每期换美术，入口横幅和底部那排页签的模板是照当期导出的，换期之后如果日志里出现「the event banner is not on the lobby」，重新导出 `EVENT_ENTRY` 和 `EVENT_TAB_*` 即可，流程代码不用动。

**第 2 步 · 活动战斗**：两个选项——「打哪个模式」选普通 / 挑战 / 两个都打，「每个模式打几场」选 1~5。普通战斗的首通给抽卡资源，开荒期建议开着。「两个都打」时两边各按你填的场次分，只开一个模式时那 5 次全给它。开荒不用一关一关点：点右下角「自动战斗」设个次数，游戏会连着打完这一关、再自动接下一关，打不过就停在那儿；已通关的关卡没有那个入口，脚本就退回成一场一场重复打。普通战斗和挑战战斗**共用每天那 5 次**，AP 用完时游戏会弹「是否补充活动AP?」，脚本**只点取消**——那个得花货币，它不替你决定。

**第 3 步 · 魔兽追踪者**：抄排行榜第一名的阵型——「编辑队伍 → 推荐部署 → 第一条的『使用』→ 确认替换」，替掉的是**队伍1**，队伍2/3 游戏不会动。然后从 EASY 开始往上推，一档只打一场：打死了 BOSS 才进下一档，打不死就停在那儿，那就是明天的起点。一场大约 4 分钟（3 队各打 20 回合），期间脚本会盯着右上角的自动战斗钮——它偶尔会自己掉回手动，掉了就重新打开。已经打穿的档，「最高伤害量」那一行会变成「完成讨伐」，脚本读到它就跳过。所以**不用记账，也不用担心换期**：新一期的面板上这四个字一个都没有，自然就从 EASY 重新开始。

**第 4 步 · 活动任务**：点底部「任务」木牌，进门只看一件事：右下角那颗「全部领取」是亮的还是灰的——亮着就按一次，把已经做完的任务奖励一次收掉，然后关掉弹出的奖励页；灰着就是今天没有可领的，一个按钮都不按。所以它不会去读任务文字，也不管这一期有几条任务、领完之后哪条会从列表里消失。「全部领取」只领做完的，没做完的照旧灰着，按下去不会误领。

**第 5 步 · 活动商店**：把活动兑换道具按你在「兑换优先级」里排的顺序花掉，**没写进去的代号就是不买**。默认是 `GachaTicket > GoddessTear > EquipUR > EquipSR > EquipMaterial > AncientCrystal > Essence > RefineCrystal > Star4`，换期想知道这期的装备/材料叫什么，看日志里扫出来的名字，直接把中文名写进去也行。

三件跟「位置不能写死」有关的事，都在代码里注释着：**买满限量的商品会沉到列表最后**（显示「购买成功」并变暗），中间的商品整体往前顶，所以每买一次都重扫一遍，**碰到第一个「购买成功」就收工**——可买的永远排在前面，这也是它只用看第一屏和滚到底那一屏的原因。付费道具（默认不买）认的是价格左边那枚**蓝钻石**：活动币的图标每期都换，钻石不换，所以数颜色而不是认商品图。装备认名字里的 `(UR)` / `(SR)` 后缀，装备名本身每期都变，后缀不变。

数量不用愁：面板上的「可购买 N 个」就是剩余限购次数，脚本按 `MAX`，而**游戏自己会把 MAX 截到余额买得起的数量**（限购 99999 个的东西，余额 4650 时 MAX 填的是 4649）。**买不动就收工**：清单是按价值排的，越靠后越不值，所以高优先级那一档还有货、只是币不够时，脚本不会拿这笔钱去买后面的便宜货——活动币每天涨、限购不会跑，今天买不起的那一档明天接着买。唯一的例外是那一档其实已经买满（只是没识别出「购买成功」），那种情况会接着下一档。

## 几点提醒

- 分辨率固定 **1280×720**，只支持模拟器，不支持真机。
- 启动前模拟器要开着。`start_algs.bat` 会自己执行 `adb connect`，不用另开命令行。
- 体力不够时不会硬刷：动手前先读体力条和单场消耗，不够就跳过这次，不会卡在那里等一个永远不会来的结算。
- 「活动」任务遇到没通关的新活动会**自动开荒**，那是真打，会消耗体力和次数。第一次跑新活动时留意一眼。
- 「推主线」也是真打，一场几分钟，三个难度都推不动的时候这一趟会花掉十几分钟——它只在每天 00:00 跑，不占你白天的时间。
- 「迷宫」走完一轮要十几分钟（游戏自己在跑，脚本只是等），中途会替你选祝福、点剧情、打最终 BOSS。
- 游戏自己弹的东西它会顺手处理：苍雾世界开局的月签到面板（领完用返回键关掉）、苍雾世界客户端更新时的「游戏需要下载额外X GB资源」（按确认，然后等它下完）、失落之剑的每日登录签到面板和偶尔弹出来的「Hot Deal!」限时礼包卡、棕色尘埃2 的「支付失败」弹窗（按确认继续）。
- **资源更新的处理两个游戏不一样**：苍雾世界那个「取消 / 确认」的框，取消只会退回标题页、下次开还是一模一样，所以脚本按确认让游戏自己下完——2.38 GB 实测五分钟，下完游戏自己往下走；进度五分钟不动（断网）或者一小时还没下完，就报停找人。棕色尘埃2 冷启动时的「更新通知」和「下载」弹窗一律不点，前者会把你甩进应用商店，后者是十几个 G 的资源下载，它直接报停并留截图，由你决定要不要更新。
- 游戏掉线、卡在某个弹窗时，脚本会把最近 60 张截图和日志存进 `log/error/`，然后自动重启游戏继续，不会一直瞎点。**游戏维护是例外，它不管，见下一节。**
- 「重启」任务是每天在日刷新后重启一次游戏进程，也是在游戏卡死时被自动调用的恢复手段，建议保持勾选。
- 竞技场的票是慢慢回的（上限 10 张），脚本一天只跑一次，攒着一起打完，不会为了一张票反复开关游戏。

## 游戏维护它不管

它不认识「维护中」那张公告页——在它眼里那只是「还没到主界面」。所以**维护期间它只会空等，不会自己恢复。**

撞上维护时，实际发生的是这些：

1. 按各游戏的启动上限空等：苍雾世界 4 分钟、失落之剑 5 分钟、棕色尘埃2 10 分钟——它认不出这是维护页，只会当成「还在加载」。
2. 等满了就存一次错误日志到 `log/error/`，重启游戏，再等一轮。
3. 就这样反复，同一个任务连着失败 3 次（中途自动调用的「重启」也算一次），调度器整个停下——日志最后一行是 `Request human takeover`，之后当天的任务一个都不会再跑。

**维护结束后它不会自己知道**，要你手动点一次「开始」，或者点一次「一键全跑 xxx」把当天的任务补上。所以维护那天最省事的做法是先把那段时间的任务停掉，等开服了再统一跑一遍；把它留在排期里，只会换来几次 4~10 分钟的空等和一个停掉的调度器。

**要更新客户端、要下载资源包**的提示是同一类，脚本只报停不动手：棕色尘埃2 的「更新通知」和「下载」一律不点，只记一条 critical 然后停下等人（细节在前面「几点提醒」里）。唯一的例外是苍雾世界的资源包——那是游戏自己在下，脚本按确认陪它等。
