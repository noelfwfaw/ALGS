# AlGS

**一个模拟器，多个游戏，勾几个任务就自动跑完的挂机脚本。**

AlGS 不要求游戏 24 小时挂着。它记住每个任务下次该什么时候跑，到点了自己启动模拟器、把该做的做完、再关掉——白天照常用电脑，凌晨那趟收菜它自己会去。

目前适配 **2 个游戏、22 个日常任务**，都在同一个模拟器里按顺序执行。

## 能做什么

### 苍雾世界（Hazeworld）

| 任务 | 它替你做的事 |
|---|---|
| **邮件** | 打开邮箱，一键领取全部附件 |
| **指挥室** | 一键收取所有产出；两支远征队按你配的任务和时长派出，到期自己回来领取、再派一次 |
| **演习** | 花掉当天的演习券打完竞技场，默认走代理作战一路扫（想看战斗过程可以关掉代理） |
| **好友** | 一键点赞全好友 |
| **任务** | 每日 / 每周 / 每月三栏的任务奖励一键领取，连积分条攒满的宝箱也一起开 |
| **通行证** | 先领通行证任务（任务给的积分才能升级），再一键领取等级奖励 |
| **支援角色** | 把每个支援角色的友情币（绿币）领掉，每日上限 50000 |
| **核心制造** | 扫荡今天开放的关卡，能刷多少刷多少，体力花完为止；扫完会再读一次体力，确认真的花出去了，没花够就再扫一遍 |

### 失落之剑（Lost Sword）

| 任务 | 它替你做的事 |
|---|---|
| **邮箱** | 数着列表右侧的红点，有未读就点「一键领取」，领完关掉奖励弹窗 |
| **推主线** | 冒险里按普通 → 困难 → 地狱依次往下推，每个难度推到打不过为止（输了停在 DEFEAT 页就换下一个难度）；章节最后一关的剧情会自己点 Skip |
| **领主突袭** | 每天先真打一场（伤害榜要这一场），再把剩下的免费次数扫荡掉；三次用完就停，不碰付费票 |
| **小队副本** | 每天一次，自动进房间匹配、等招募和战斗结束，结算页「CLEAR」后返回 |
| **星辰轮回** | 三个冒险区域各挑战一次，每个区域打一到两波，打完退出 |
| **副本扫荡** | 进任意一个可扫荡的副本，一键选择把金币 / 经验书 / 属性石三个日常免费次数一起扫掉 |
| **迷宫** | 点「自动进行」把节点优先级配好（祝福最优先、特殊事件最后），然后看着它自己走；中途的剧情、祝福三选一、最终 BOSS 都会替你处理 |
| **活动** | 新活动自动开荒（剧情跳过、战斗自己打、通关五秒后自己进下一关），开荒完把已通关的关卡一键扫荡；标着「探险完成」的活动直接跳过 |
| **竞技场** | 花掉攒着的票券打完竞技场，场上有晋级赛就先打晋级赛；打完把赛季任务的参与 / 资源 / 段位三页领空 |
| **圆桌升级** | 点「升级」提升骑士团等级，一直升到金币和经验书不够为止 |
| **好感对话** | 按配置的角色名逐个找到角色，把当天的好感对话次数用掉（对话里的选项自动选第一条） |
| **商店** | 每日 / 每周 / 每月三个页签的免费礼包各领一次，只碰免费的那张卡，付费的一个不动 |
| **宝藏探索** | 领取挂机累积的宝藏，并用掉每天一次的免费快速探查（弹出来要 90 钻时自动放弃） |
| **任务奖励** | 每日 / 每周 / 史诗三个页签全部领取，顺手把赛季通行证里所有能领的等级奖励也领掉 |

每个任务都能单独开关。只想收个菜就把其它勾掉，那天就只为这一件事启动模拟器。

## 它什么时候自己跑

这是 AlGS 和普通挂机脚本最不一样的地方：**每个任务自己排下一次的时间，不在该跑的时候它不碰模拟器。**

| 游戏 | 任务 | 什么时候跑 | 为什么是这个时候 |
|---|---|---|---|
| 苍雾世界 | 邮件 / 好友 / 支援角色 | 每天 05:00 | 日刷新，跑一次就够 |
| 苍雾世界 | 核心制造 | 05:00 / 17:00 | 一管体力约半天回满，一天跑两次正好把两管都花掉 |
| 苍雾世界 | 任务 / 通行证 | 05:00 / 12:00 / 18:00 / 23:00 | 任务是在你玩的时候陆续完成的，只在早上领一次等于把一天的任务堆到第二天 |
| 苍雾世界 | 演习 | 05:00 / 17:00 | 演习券每小时回 1 张、上限 15 张，一天只跑一次会白白浪费 9 张 |
| 苍雾世界 | 指挥室（远征） | 最早回来的那支队伍 + 5 分钟 | 队伍什么时候回来是面板上写着的时间，不是配置里的 8 小时 |
| 失落之剑 | 邮箱 / 推主线 / 领主突袭 / 小队副本 / 星辰轮回 / 副本扫荡 / 活动 / 竞技场 / 圆桌升级 / 好感对话 / 商店 / 宝藏探索 | 每天 00:00 | 这个游戏的日刷新是零点；这些都是每天一次的次数，攒着一次做完 |
| 失落之剑 | 迷宫 | 每周一 00:00 | 一周只能走一次，走完地图上写「完成」，再点也没用 |
| 失落之剑 | 任务奖励 + 赛季通行证 | 每次游戏会话结束时领一遍（跑完勾的任务、关游戏之前），另有 00:00 兜底 | 奖励跟人走，但排在所有任务后面，不会挡住你真正想跑的东西 |

**两个游戏的日刷新时间不一样，各按各的算**：苍雾世界 05:00，失落之剑 00:00。这个时间是每个游戏自己的属性，脚本不会拿一个游戏的时间去排另一个游戏的任务。

排在同一时刻的任务会连着跑完，共用一次启动——苍雾世界 05:00 那批是「邮件 → 指挥室 → 支援 → 演习 → 好友 → 核心制造 → 通行证 → 任务」，失落之剑 00:00 那批是一次冷启动把当天的次数全花掉，不会为了下一个任务再开一次模拟器。队列跑空之后、关游戏之前，脚本还会顺手把任务奖励和通行证领一遍，所以「今天只勾了收菜」也不会漏掉它们。

## 怎么用

1. **把模拟器准备好**：MuMu，分辨率 **1280×720**，adb 端口 **127.0.0.1:16640**，装好游戏并登录。
2. **双击 `start_algs.bat`**。它会先连上模拟器，再起管理界面。
3. **浏览器打开 http://127.0.0.1:22267** 。
4. 在「Alas → Alas设置 → 模拟器设置」里确认「模拟器 Serial」是 `127.0.0.1:16640`，「游戏服务器」选一个**已经装好**的游戏（这只是决定启动时先打开哪个，之后按任务自动切）；然后在对应分组下勾上要跑的任务（名字就是上面那两张表），逐个填好选项，保存。
5. 想立刻跑就点「开始」，或者什么都不做——到点它自己会跑。

关掉浏览器不影响它，脚本在后台继续按排期工作。

> **两个游戏可以同时勾。** 每个任务开跑前，脚本会把属于它的那个游戏切到前台；切的时候会先关掉另一个——模拟器是手机规格，两个游戏同时开着，系统迟早会杀掉其中一个，看起来就像随机闪退。代价是每次换游戏都要冷启动一次（失落之剑一分半到两分钟，这段时间它只是在等游戏加载）。

## 配置要点

**远征（苍雾世界 · 指挥室）**：两支队伍各配一个任务（训练 / 防卫 / 攻击 / 火力 / 支援）和一个时长（4 / 8 / 12 小时），不用的队伍把任务选「不派遣」。已经派出去的队伍时长在游戏里是锁死的，脚本只负责到期领取再照配置重新派，所以改配置只影响下一次派出。

**核心制造（苍雾世界）**：周一到周日各配一个类型（生命 / 攻击 / 护甲 / 暴击 / 爆发），选「不刷」就跳过那天。场数只有一个「刷几场」：填 `0` 表示有多少体力刷多少，填具体数字就只刷那么多场。关卡不用配，游戏会沿用你上次打的那一关，出新关卡也不用改脚本。

**演习（苍雾世界）**：默认用代理作战（游戏自己打完，速度快、不挑队伍）。关掉「代理作战」就变成一场一场看战斗过程，慢很多，一般不需要。

**领主突袭（失落之剑）**：只有一个「扫荡剩余次数」开关。开着就是打一场 + 把剩下的免费次数扫掉；关掉就只打那一场，剩下的次数留给你自己扫。

**好感对话（失落之剑）**：填 6 个角色名，照游戏里「角色」页卡片下方写的那个填（简繁要和游戏一致）。脚本在角色网格上按名字找，找不到的、今天已经聊过的会跳过；一个都不填这个任务就空转，不会乱点。

**任务奖励（失落之剑）**：默认在每次会话结束（跑完你勾的任务、关游戏之前）领一遍，所以平时不用管排期；关掉开关就只剩每天 00:00 那一次兜底。

**推主线（失落之剑）**：没有选项，勾上就是每天推一次。三个难度各自推到你打不过为止，所以推不动的日子它也只打一场就换难度，不会反复送。

**宝藏探索（失落之剑）**：两个开关——「领取宝藏」收挂机收益，「每日一次免费快速探查」用掉当天那次免费机会。免费次数用完再点就要 90 钻，脚本看出价格变成钻石就只关弹窗、不付钱。

**迷宫（失落之剑）**：一周一次，没有选项。节点优先级是照攻略写死的（女神的祝福 > BOSS > 宝箱 > 复活 > 死神的试炼 > 特殊事件），要改只能改代码；想让游戏自己排就关掉这个任务，手动进一次。

## 几点提醒

- 分辨率固定 **1280×720**，只支持模拟器，不支持真机。
- 启动前模拟器要开着。`start_algs.bat` 会自己执行 `adb connect`，不用另开命令行。
- 体力不够时不会硬刷：动手前先读体力条和单场消耗，不够就跳过这次，不会卡在那里等一个永远不会来的结算。
- 「活动」任务遇到没通关的新活动会**自动开荒**，那是真打，会消耗体力和次数。第一次跑新活动时留意一眼。
- 「推主线」也是真打，一场几分钟，三个难度都推不动的时候这一趟会花掉十几分钟——它只在每天 00:00 跑，不占你白天的时间。
- 「迷宫」走完一轮要十几分钟（游戏自己在跑，脚本只是等），中途会替你选祝福、点剧情、打最终 BOSS。
- 游戏自己弹的东西它会顺手处理：苍雾世界开局的月签到面板（领完用返回键关掉）、失落之剑的登录奖励和「已获得道具」弹窗。
- 游戏维护、掉线、卡在某个弹窗时，脚本会把最近 60 张截图和日志存进 `log/error/`，然后自动重启游戏继续，不会一直瞎点。
- 「重启」任务是每天在日刷新后重启一次游戏进程，也是在游戏卡死时被自动调用的恢复手段，建议保持勾选。
- 竞技场的票是慢慢回的（上限 10 张），脚本一天只跑一次，攒着一起打完，不会为了一张票反复开关游戏。
