# AlGS

**单模拟器多游戏任务调度脚本**

AlGS 基于 [AzurLaneAutoScript](https://github.com/LmeSzinc/AzurLaneAutoScript) 框架改造：在一个 Android 模拟器中运行多个游戏，按任务排期依次执行。每个任务独立记录下次运行时间，到期后自动启动模拟器完成对应操作，结束后关闭游戏。

当前支持 5 个游戏、41 个任务，另有 1 个不参与排期的独立工具。

<a name="start"></a>

## 🚀 使用

1. 准备 MuMu 模拟器，分辨率设为 1280×720，安装并登录游戏。
2. 运行 `start_algs.bat`，脚本会连接模拟器并启动管理界面。
3. 在浏览器中打开管理界面（默认端口 22267）。
4. 在「Alas 设置 → 模拟器设置」中填写模拟器的 adb 地址（IP 与端口），并选择已安装的游戏服务器。该选项只决定启动时先打开哪个游戏，后续按任务自动切换。
5. 在对应分组下勾选任务，填写选项后保存。
6. 点击「开始」立即执行，或等待排期自动运行。
7. 需要立刻执行某个游戏的当轮任务时，点击「一键全跑 <游戏>」。该操作仅将已启用任务的下次运行时间置为当前时间，调度器按优先级依次执行；未启用的任务不会被打开。

关闭浏览器不影响后台调度。

<a name="config"></a>

## ⚙️ 配置

### 苍雾世界

- 远征：两支队伍分别配置任务（训练、防卫、攻击、火力、支援）与时长（4、8、12 小时），不使用时选择「不派遣」。已派出的队伍时长不可修改，配置只影响下一次派出。
- 核心制造：周一至周日各配置一个关卡类型，选择「不刷」跳过当天。场数为 `0` 时按现有体力尽量刷，否则按填写数量执行。
- 演习：默认使用代理作战。关闭后逐场播放战斗过程。
- 精英商店：过滤器可选「全部」「自定义」「不买」。购买清单一行一条规则，按名称子串匹配，`>` 分隔多个关键词，`!` 开头表示排除，`#` 开头为注释。排除规则在所有档位下生效。
- 后勤商店：过滤器与清单格式同精英商店，默认「全部」并排除盾币。
- 荣誉凭证：清单用于校验货架第一格是否为指定商品，名称不匹配则不购买。

### 失落之剑

- 好感对话：填写角色名，简繁需与游戏内一致，未找到或当日已完成的角色跳过。
- 领主突袭：开启「扫荡剩余次数」后完成一场实战并扫荡剩余免费次数；关闭后仅执行一场。
- 宝藏探索：可分别开启领取宝藏与每日免费探查。免费次数用尽后需要消耗钻石，脚本会跳过。
- 公会：有红点时消耗金币完成捐献与投资，金币不足时不执行。
- 迷宫：节点优先级固定，未成功进入或确认 BOSS 时推迟 3 小时重试，仅在地图显示完成后排至下周。
- 兑换码：兑换记录保存在本地，删除对应条目可重新尝试。

### 棕色尘埃2

- 快速狩猎：八项次数分为两组预算，狩猎场、金币、史莱姆合计不超过 15 次，圣石洞穴五种属性合计不超过 10 次，超出时拒绝执行。
- 活动：可分别设置战斗模式与每个模式的场次，活动商店按兑换优先级消费活动币。
- 兑换码：兑换记录保存在本地，删除对应条目可重新尝试。

### 星之救援者（工具）

- 昵称：留空时每轮随机生成，仅支持字母与数字，长度 4~16 位。
- 达标条件：「任意一个角色」在任一目标达标时停止；「全都要」需所有目标均达标。
- 目标角色：最多 7 个，格式为 `名字@团`，同名角色需通过团名区分。
- 停止节点：可分阶段运行，用于调试或分段验证。

<a name="notes"></a>

## ⚠️ 注意事项

### 环境

- 分辨率固定 1280×720，仅支持模拟器。
- 启动前需要模拟器处于运行状态，`start_algs.bat` 会自动完成 adb 连接。
- 体力或次数不足时任务会跳过，不会等待结算。

### 资源消耗

- 活动开荒、推主线、迷宫、竞技场均会实际消耗体力、次数或票券。
- 刷初始会清空账号上可抽取的资源，并可能重置服务器账号进度，仅适用于空号或小号。该功能仍在测试阶段，兼容性有限。

### 异常处理

- 游戏卡死、掉线或停留在弹窗时，脚本会保存最近 60 张截图与日志，随后重启游戏继续执行。
- 无法识别维护公告页，维护期间会按各游戏的启动上限等待；同一任务连续失败 3 次后调度器停止，需要手动重新开始。
- 错误推送：出问题时会按 `Alas → Error → OnePushConfig` 里的 Onepush 配置推一条消息，不用盯着 WebUI。包括脚本错误、需要人工接管、认不出页面、配置或设备初始化失败、同一任务连续失败 3 次、工具跑失败（例如刷初始重置账号没成功）；游戏卡死、误点过多、客户端异常、游戏不在运行这类会自动重启恢复的错误也会推一条。运行以失败结束时，WebUI 侧栏显示为出错状态，而不是「已完成」。没填 `provider` 时（默认 `provider: null`）不推送；配置方法见 [Onepush 配置](https://github.com/LmeSzinc/AzurLaneAutoScript/wiki/Onepush-configuration-%5BCN%5D)。
- 客户端更新与资源下载提示只记录并停止，不会代为操作；苍雾世界的资源包是例外，脚本会确认并等待下载完成。
- 失落之剑闲置约 3 分钟后会隐藏界面，脚本会自动恢复后再继续。

## 🛠️ 开发

以下协作资料只存在于本机，**不进版本库**：

| 路径 | 内容 |
|:---|:---|
| `.workbuddy/skills/alas-multigame-dev/` | 技能真源：`SKILL.md` + `references/`（含 155 条硬约束） |
| `.workbuddy/memory/` | 共用记忆：`MEMORY.md` 为权威约定，`YYYY-MM-DD.md` 为实测日志 |
| `CODEBUDDY.md` | CodeBuddy 本机入口；可能被工具重新生成，与 `MEMORY.md` 冲突时以 `MEMORY.md` 为准 |

`.codebuddy/skills/` 与 `.trae/skills/` 是指向技能真源的**目录联接**，三个工具读写的是同一份文件。
新 clone 或换机器后：先恢复 `.workbuddy/` 与 `CODEBUDDY.md`，再运行 `dev_tools\link_agent_skills.bat`
重建联接（幂等，可重复执行）。资料缺失时调度器照常运行，只是 AI 助手拿不到技能与历史踩坑记录。
