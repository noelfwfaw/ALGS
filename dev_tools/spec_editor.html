页面（一个页面一张卡）

适应 Ctrl + 滚轮也能缩放
把游戏截图拖进来，或 Ctrl+V 粘贴
然后按住左键框出「这个东西」






  

    

      
场景速查：你想做的事 → 怎么填

      
    

    
一张卡 = 一个页面。下面左列是你要做的事，右列是对应的填法。

    

      
点一下就拿完（签到、邮件、领奖）看到 领取按钮 → 点它 → 留本页 → 最多 3；再加一行 变灰的那个 → 不点

      
点完弹个窗这行选「点完会：弹个窗要关掉」再选弹窗；并在它上面加一行「看到弹窗 → 点它」

      
按钮有亮 / 灰两种样子两个元素都建成 颜色；亮的点，灰的那行选「不点」当结束条件；灰的记得把「连续」填 3

      
图标是镂空的、背景会变类型选 镂空图标，再选笔画是亮还是暗

      
判据在 A，要点的是 B看到 A → 然后「点另一个东西」→ 选 B

      
看到弹窗，点空白处关掉看到弹窗 → 然后「点屏幕某处」→ 去画布上点一下

      
数字够才做（体力、次数、金币）类型选 数字，填条件和阈值（如 ≥ 30）

      
一天做 N 遍（刷图、十连）④ 这一页重复 N 次

      
刷到成功为止（初始号）④ 选「刷到目标为止」

      
只是一小段过场，认不出任何东西在 ⑤ 备注里写清楚，让 AI 用「等画面不动」

      
一条线的引导：一串按钮依次点顶部勾上 串联链：生成一条循环遍历所有按钮，不再一页一个循环

      
SKIP / 跳过 / 关闭，一直都在类型选 常驻按钮，框住它、填占比区间；它会被提到链条最前面单独点，不会抢后面的步骤

      
过完引导才许点某个按钮把「过引导」写在前面的行，再在「点自动战斗」那行勾上 分段：上一段没做完，下面一段根本不会开始

      
要输入文字（昵称、兑换码）框住输入框 → 然后「输入文字」→ 填内容（只能英文数字）→ 最多 1 次；再框一下输入后变亮的「确认」

      
要滚动列表、要比价、要记账这些卡片表达不了，写进 ⑤ 备注

    

    
    
      
  • 行的先后 = 优先级：弹窗那一行要放在「点按钮」上面，否则窗开着也会去点按钮。
    • 
      
  • 「不点」那一行 = 这一页的结束条件，生成时会自动提到循环最前面。
    • 
      
  • 判据越专一越好：只在这个页面出现的东西才拿来认页面，别用页签和通用按钮。
    • 
      
  • 行序 ≠ 先后：行序只决定"同时成立时先做谁"。要"必须先做完 A 才能做 B"，只能用分段。
    • 
      
  • 框到纯色等于没框：模板匹配对纯色块会给任何画面 1.00 分，脚本就会"永远认为它在"。生成时会检查 std，低于 2 直接报错。
    • 
      
  • SKIP 不要用图、也不要用 OCR：它的背景一直在变，图会被带偏；OCR 慢且认不了日韩。用常驻按钮数白色像素占比，实测有 2.8~13.5%、没有 0.0%。
